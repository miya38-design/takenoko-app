# タケノコ買取受付アプリ

タケノコの買取受付・集計・履歴管理のWebアプリです。

## 機能
- 受付入力（氏名サジェスト・重量入力・リアルタイム金額計算）
- 受付一覧（当日データの確認・削除）
- 集計（納品書・LINE報告テキスト・PDF出力）
- 履歴・分析（日別/週別/月別/年別集計・CSV/PDF出力）
- Firebase Firestore によるクラウドデータ保存（複数端末共有対応）

## 技術スタック
- HTML / CSS / JavaScript（バニラ）
- Firebase Firestore（データ保存）
- jsPDF + jspdf-autotable（PDF出力）
- GitHub Pages（ホスティング）
